# 🚀 SIPEKAN - Quick Start Guide

## Cara Menjalankan Aplikasi (1 Command)

### Windows (PowerShell)
```powershell
.\start-server.ps1
```

### Windows (Command Prompt)
```cmd
start-server.bat
```

### Manual Command
```bash
cd d:\sipekan-fe-be\sipekan
php artisan serve
```

## ✅ Hasil
Setelah menjalankan command di atas, aplikasi akan tersedia di:
- **URL**: http://127.0.0.1:8000 atau http://localhost:8000
- **Frontend**: React SPA terintegrasi
- **Backend API**: Laravel REST API di /api/*

## 🔧 Setup Awal (Hanya Sekali)

### 1. Build Frontend ke Laravel Public Directory
```bash
cd d:\sipekan-fe-be\sipekan-frontend
npm run build:laravel
```

### 2. Jalankan Laravel Server
```bash
cd d:\sipekan-fe-be\sipekan
php artisan serve
```

## 📁 Struktur Integrasi

```
sipekan/
├── public/
│   ├── assets/           # Frontend build output
│   │   ├── index-*.js    # React app bundle
│   │   └── index-*.css   # Styles
│   ├── .vite/
│   │   └── manifest.json # Asset manifest
│   └── index.html        # Generated by Vite
├── resources/
│   └── views/
│       └── app.blade.php # Blade template untuk serve React
└── routes/
    ├── api.php           # API routes (/api/*)
    └── web.php           # Frontend routes (catch-all)
```

## 🔄 Update Frontend

Setiap kali ada perubahan di frontend:
```bash
cd d:\sipekan-fe-be\sipekan-frontend
npm run build:laravel
```

Server tidak perlu direstart, refresh browser saja.

## 🌐 API Endpoints

Semua API endpoint tetap tersedia di `/api/*`:
- POST `/api/auth/login` - Login
- GET `/api/balita` - List balita
- Dan lainnya...

## 🔐 Environment Variables

Frontend production config (`.env.local`):
```env
VITE_API_URL=/api
VITE_APP_NAME=SIPEKAN
VITE_APP_ENV=production
```

## 🐛 Troubleshooting

### Port sudah digunakan
```bash
# Gunakan port lain
php artisan serve --port=8001
```

### Frontend tidak muncul
1. Build ulang frontend: `npm run build:laravel`
2. Clear cache Laravel: `php artisan cache:clear`
3. Restart server

### API tidak terhubung
- Pastikan `VITE_API_URL=/api` di `.env.local`
- Build ulang frontend setelah mengubah env

## 💡 Tips

- Untuk development frontend dengan hot reload, tetap bisa gunakan:
  ```bash
  npm run dev  # Port 5173 dengan proxy ke Laravel
  ```
  
- Untuk production/testing integrasi:
  ```bash
  npm run build:laravel  # Build dan deploy
  php artisan serve       # Jalankan server
  ```
